# QA checklist: run before showing a draft to Jim

> Part of the Editorial Layer (ADR 0009). The composing agent checks every line against
> the draft; any failure means fix the draft first, not flag it.

## Facts
- [ ] Every name, pronoun, school, and programme detail matches the source story exactly.
- [ ] Children and youth appear by FIRST NAME ONLY, everywhere including the subject line.
- [ ] Every number traces to the supplied stats catalog or the source story itself.
- [ ] No progress claim assumes curriculum facts not in the source.
- [ ] No invented signature detail; anything distinct about the child is in the source.

## Craft
- [ ] The child sounds distinct, not like a template with a name swapped in.
- [ ] The donor "you" appears within the first ~150 words.
- [ ] The quote (if any) adds new information and sounds like a real coach.
- [ ] Exactly ONE direct ask; the P.S. reinforces the same idea.
- [ ] Opening reaches the child within two or three sentences.
- [ ] US-donor phrasing throughout ("learning with Masinyusane", not "on programme").

## Mechanics
- [ ] No em dash anywhere. No emoji anywhere.
- [ ] Exactly one `<!--MID_CTA-->` marker, placed after the arc resolves.
- [ ] No logo, donate button, social links, or lead photo in the body (chrome adds them).
- [ ] Inline photos (non-lead only) use the contract img markup, correct child, correct spot.
- [ ] Subject line: first name only, concrete, no clickbait.
